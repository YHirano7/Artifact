## 3. 画面一覧

| 画面 ID | 画面名 | 利用者 | 概要 |
|---|---|---|---|
| SCR-001 | ログイン | 会員 / 管理者 | ID とパスワードで認証する |
| SCR-002 | 会員登録 | 会員 | 必要事項を入力して仮登録する |
| SCR-003 | マイページ | 会員 | 登録情報の参照・変更 |
| SCR-101 | 会員検索 | 管理者 | 条件を指定して会員を検索する |

## 4. 機能仕様

### 4.1 会員登録

1. 会員が SCR-002 で必要事項を入力する
2. システムは入力値を検証し、仮登録状態で会員を作成する
3. 確認メールを送信する
   - 有効期限は 24 時間
   - 期限切れの場合は再送できる

```mermaid
sequenceDiagram
    participant U as 会員
    participant W as Web 画面
    participant A as 会員 API
    participant M as メール配信
    U->>W: 登録情報を入力
    W->>A: POST /members
    A-->>W: 201 Created（仮登録）
    A->>M: 確認メール送信を依頼
    M-->>U: 確認メール
```

#### 入力項目

| 項目 | 必須 | 形式 | 備考 |
|---|---|---|---|
| メールアドレス | ○ | RFC 5322 準拠 | 登録済みの場合はエラー |
| 氏名 | ○ | 全角 50 文字以内 | |
| パスワード | ○ | 12 文字以上、英数記号を含む | |

> [!WARNING]
> パスワードは画面・ログ・メールのいずれにも平文で出力しないこと。

## 5. 外部インターフェース

### 5.1 会員登録 API

`POST /api/v1/members`

```json
{
  "email": "taro@example.com",
  "name": "山田 太郎",
  "password": "********"
}
```

| ステータス | 意味 |
|---|---|
| 201 | 仮登録成功 |
| 400 | 入力値エラー |
| 409 | メールアドレス重複 |
