長文脈外挿の破綻は「臨界次元以降の未学習角度と高周波喪失」で起き、内部では「Residual Stream上のK-Composition」が2層でInduction Headを創発させる

対象：②RoPE長文脈拡張（PI / NTK / YaRN）→ ③Transformer Circuits・Residual Stream・Induction Heads
上級の核心結論：RoPEを全次元一律に縮めるPIは高周波（局所トークン識別能）を破壊するため、波長別のNTK-by-parts補間＋Softmax温度調整（YaRN）が不可欠［Peng+ 2024］。そしてAttention層は単なる重み付き平均ではなく、残差ストリームの部分空間を介した第1層・第2層の行列合成（K-Composition）によって文脈コピー回路「Induction Head」を形成する［Elhage+ 2021］。

次元 d の波長 λd = 2π·100002d/D が訓練長 Ttrain を超える低周波次元は、事前学習中に1周期（2π）すら完走していない［Liu+ ICLR 2024］。LLaMA2（d=128, Ttrain=4096）では最初の92次元しか1周期を経験しておらず、残り36次元が未学習の角度領域（OOD）へ突入しAttentionスコアが爆発する。
臨界次元: d_extra = 2⌈(d/2)·log_10000(T_train / 2π)⌉ = 92 (LLaMA2)

位置インデックスを g(m) = m/s, h(θd) = θd で既知範囲 [0, L] に押し込む。外挿に比べ補間の上界は約600倍（2·294.73倍）小さいが、全次元の周波数を一律 1/s 倍に縮めるため高周波成分が消失し、隣接トークンの微小な位置差を識別できなくなる［Tancik+ 2020 NTK理論 / Peng+ 2024 L192］。

Tier 2（Transformer内部回路）：Residual Stream の線形分解と、2層 K-Composition による Induction Head（[A][B] … [A] → [B]）の構成原理 出典: Elhage, Nanda, Olsson, Olah et al. "A Mathematical Framework for Transformer Circuits" (Anthropic 2021)
⑤ Residual Stream 共有通信チャネルと仮想重み 計算せず通信のみ
・完全な線形加算構造：残差ストリーム xℓ = x0 + ∑ Attn + ∑ MLP は非線形活性化を挟まない（ResNetとの決定的違い）。各層は線形射影で部分空間から「読み出し（Read）」、計算結果を別の部分空間へ「書き足す（Write）」［L147-154］。
・Virtual Weights（仮想重み）：残差ストリームが線形であるため、離れた第 ℓ1 層の出力重み WO1 と第 ℓ2 層の入力重み WI2 の積 WI2 WO1 が2層を直接結ぶ暗黙の通信チャネルとなる［L158］。
2層Attention-Only展開: T = Id + ∑_h A^h ⊗ W_{OV}^h + ∑_{h2,h1} (A^{h2} A^{h1}) ⊗ (W_{OV}^{h2} W_{OV}^{h1})

⑥ 単一Headの独立2回路分解 QK回路（Where）× OV回路（What） ランク dhead ≪ dmodel
通常の「全ヘッド結合＋WO乗算」は計算効率のための実装表現にすぎず、数学的には各ヘッド h が独立にランク dhead（64〜128）の2つの低ランク合成行列を持つ［L113-119］：
・QK回路（WQKh = WQhT WKh）：どのトークンからどのトークンへAttentionを向けるか（Attentionパターン Ah = softmax(xT WQKh x)）だけを決定。
・OV回路（WOVh = WOh WVh）：注意を向けた元トークンの残差ストリームから何を読み出し、出力ロジット（WU WOVh WE）にどう影響させるかを決定。
1層ヘッド出力: h(x) = (A^h ⊗ W_{OV}^h)·x, A^h = softmax*(x^T W_E^T W_Q^{hT} W_K^h W_E x)

合成
⑦ Induction Head の2層協調動作 なぜ1層では不可能で2層必要なのか 正固有値コピー行列［L536］
系列 … [A][B] … [A] の末尾 [A]（位置 T）から過去の [B]（位置 j+1）へ注意を向けるには、「位置 j+1 のトークン自身の値 B」ではなく「その1つ前（位置 j）が A だったこと」でKeyを検索しなければならない［L524, L636］：
Step 1（Layer 0: Previous Token Head h−1）：位置 j+1 が直前の位置 j（トークン A）に注意を向け、OV回路 WOVh−1 で「直前トークン A の情報」を位置 j+1 の残差ストリーム部分空間へ書き込む。
Step 2（Layer 1: Induction Head h2）：現在位置 T（トークン A）のQueryと、Layer 0が書き込んだ部分空間を K-Composition（WQKh2 WOVh−1） で読んだ位置 j+1 のKeyが一致し、位置 j+1 のトークン B をOV回路で出力へコピーする！
QK内のK-Composition項: Id ⊗ A^{h_{-1}} ⊗ (W_E^T W_{QK}^{h_2} W_{OV}^{h_{-1}} W_E) ⇒ [A][B]…[A] で位置 [B] のスコア最大化

Transformer Circuits の階層的分解：0層・1層・2層モデルの厳密な役割と3種のヘッド合成（→ 主図 Tier 2） 出典: Elhage et al. "A Mathematical Framework for Transformer Circuits" (Anthropic 2021)
回路階層・合成種別 数学的表現（パス展開・Frobeniusノルム指標） 獲得されるアルゴリズム的能力と内部回路の挙動
0層 Transformer
（Direct Path）		 T0 = WU WE
（Embedding から Unembedding への直接経路）		 直前トークン xt のみから次トークン xt+1 を予測する純粋な Bigram 統計モデル。深いモデルでもこの直接経路（Direct Path）は常に残差ストリームのベースラインとして機能する。
1層 Attention-Only
（Skip-Trigram 回路）		 T1 = Id + ∑h∈H1 Ah ⊗ (WU WOVh WE)
（各ヘッドが独立に1ステップ文脈を参照）		 現在のトークン [B] と過去のトークン [A] のペアから次トークン [C] の確率を上下させる Skip-Trigram（[A]…[B] → [C]） を表現（例：Copying / メモリ消去負固有値ヘッド）。しかし「過去で [A] の直後に来た任意トークン」は検索できない。
Q-Composition
（Query合成）		 ‖WQKh2 T WOVh1‖F / (‖WQKh2 T‖F · ‖WOVh1‖F) 第2層ヘッド h2 がQueryベクトルを作る際に、第1層ヘッド h1 が残差ストリームへ書き込んだ情報を読み出す合成（「何を探しに行くか」を前層の出力で条件づける）。
K-Composition ★
（Key合成 / Induction）		 ‖WQKh2 WOVh1‖F / (‖WQKh2‖F · ‖WOVh1‖F)
（2層トイモデルで唯一顕著に発達［L466-472］）		 第2層ヘッド h2 がKeyベクトルを作る際に、第1層ヘッド h1（Previous Token Head）が書き込んだ「1つ前のトークン情報」を読み出す。これにより自分の内容ではなく「自分の前に何が来たか」で検索される Induction Head が成立する。
V-Composition
（Value合成 / Virtual Head）		 ‖WOVh2 WOVh1‖F / (‖WOVh2‖F · ‖WOVh1‖F)
項: (Ah2 Ah1) ⊗ (WU WOVh2 WOVh1 WE)		 第1層ヘッドが動かしたValue情報を、第2層ヘッドがさらに別の位置へ転送する「仮想Attentionヘッド（Virtual Attention Head）」。2層Attention-Onlyモデルではアブレーションしても損失への寄与は微小で、K-Compositionが支配的［L542-558］。
① 100倍の帯域ボトルネック Elhage+ 2021 L166
1つのMLP層だけで残差ストリームの4倍のニューロンを持つため、50層モデルの25層目では残差ストリーム次元数の100倍のニューロン群が100倍の後続ニューロン群とSuperposition（重ね合わせ）状態で通信するボトルネック活性となる。
出典: Transformer Circuits Framework L166
② メモリ消去ヘッドと負固有値 Elhage+ 2021 L168
残差ストリームに一度書かれた情報は明示的に消さない限り残り続ける。そのため一部のMLPニューロン（入出力重みのコサイン類似度が負）やAttention Head（WOV が大きな負の固有値を持ち現在トークン自身を見る）が「情報の消去（Memory Management）」を担う。
出典: Transformer Circuits Framework L164-168
③ Privileged Basis と Adam Elhage+ 2023
理論上は残差ストリームの座標軸に特別な意味は無いはずだが、実際のLLMでは特定座標に他次元の最大20倍に達するOutlier値（層あたり20〜60次元、尖度 Kurtosis > 3）が出現する。LayerNormや浮動小数点精度ではなくAdamの次元別正規化項が対称性を破る主因。
出典: Privileged Bases (2023) L23-59
④ Logit Lens による中間観測 nostalgebraist / Nanda
最終層を待たずに途中層 ℓ の残差ストリーム xℓ（あるいは個別Head/MLPの出力）に直接 Unembedding 行列 WU を掛けて語彙ロジットへ射影する手法。層を下るごとに予測分布が段階的に正解へ収束していく過程を可視化できる。
出典: Neel Nanda Glossary / Interp Atlas
⑤ 勾配帰属の飽和トラップ Elhage+ 2021 L636
Induction Headが確信を持って過去のトークン [B] に注意を向けるとき、Softmaxが飽和してKey側の勾配がほぼゼロになる。そのため単純な勾配ベースのSaliency手法ではK-Compositionで決定的な役割を果たした1つ前の [A] の寄与を見落とす。
出典: Transformer Circuits Framework L636
⑥ 小基底 RoPE (b=500) の発見 Liu+ ICLR 2024

概念比較①：位置の外挿（Extrapolation） vs 位置の補間（Interpolation） Chen+ (2023) / Peng+ (2024)
外挿（Extrapolation）：訓練時と同じ位置関数・基底のまま m > L の未学習位置を入力する方式（臨界次元以降の未学習位相差でAttentionスコアが爆発）。
補間（Interpolation）：位置インデックスや周波数 θd をスケール変換し、訓練済みの位相範囲内に収める方式（PIは全周波数一律圧縮、NTK-by-parts/YaRNは高周波の波長を維持したまま低周波のみ補間）。
概念比較②：QK 回路（Where to move） vs OV 回路（What to move） Elhage+ (2021) / ARENA
QK 回路（WQT WK）：残差ストリーム上のどのトークンペア間に強いAttention重み Aij を張るか（情報の移動元と移動先）を計算する双線形形式。
OV 回路（WO WV）：移動元トークンに100%の注意が向いたと仮定したとき、そのトークンのどの特徴を読み出して移動先のロジットをどう増減させるか（正固有値＝コピー、負固有値＝抑制/消去）を決定する線形写像。
概念比較③：Literal Copying（文字通りコピー） vs Fuzzy Nearest Neighbors（類推コピー） Olsson+ (2022) L141-151
小規模モデルの Induction Head：繰り返しランダム系列上で定義される [A][B] … [A] → [B] の厳密な同一トークン検索（Prefix Matching ＋ Copying）。
大規模モデルの Induction Head：同じヘッドが抽象表現空間上で動作することで、[A*][B*] … [A] → [B]（A≈A*, B≈B*：例えば異言語間の対応単語や概念類推）を実行する「文脈内最近傍探索器」へと連続的に拡張される。
