LLM内部回路 中級 / Rank I

推論以前の失敗（算術・多言語格差・Glitch）は「トークン分割境界と未学習埋め込み」で起き、位置は「RoPE回転行列」で相対距離化される

対象：①トークナイザ（BPE / Unigram / SentencePiece）→ ②Embedding と位置符号化（RoPE / ALiBi）
中級の核心結論：モデル構造の欠陥に見える奇妙な失敗の大半は「独立した前処理段であるトークナイザの分割単位」に遡る［Karpathy 2024］。文字列は離散ID列 idx を経て初期残差ストリーム x0 となり、Attention内積で相対距離 (m − n) のみに依存する2次元回転（RoPE）を受ける。

ステージ①：正規化・事前分割・サブワードトークナイザ（String → Token IDs） LLM本体とは別コーパス・別アルゴリズムで事前学習
①-A 言語非依存パイプライン SentencePiece と Regex 事前分割 空白 = ▁ (U+2581)
・Lossless Tokenization［Kudo & Richardson 2018］：空白も通常文字 ▁（U+2581）へエスケープし、Decode(Encode(Normalize(text))) == Normalize(text) の完全可逆性を保証。
・Regexカテゴリ境界［Karpathy 2024］：GPT-2/GPT-4（cl100k_base）は正規表現で文字・数字・記号のカテゴリ境界を先に割り、カテゴリを跨ぐ不自然なマージを禁止する。
①-B 辞書圧縮型 Byte-Pair Encoding (BPE)［Sennrich+ 2016］ 貪欲・決定論的マージ
初期語彙（UTF-8の256バイト）から開始し、隣接する最頻出ペア ('A', 'B') → 'AB' を反復的に結合して語彙サイズ |V| = 256 + Nmerges を構築。推論時は学習時のマージ優先順に従い決定論的に置換する（確率モデルを持たない手続き型）。
①-C 生成確率モデル型 Unigram LM と Subword Regularization［Kudo 2018］ EM + Viterbi DP
大きなシード語彙から開始し、①EMアルゴリズムで部分語生起確率 p(xi) を推定 → ②除去時の対数尤度減少量 lossi が小さい下位 (1−η)% を反復剪定。推論時は分割格子（Lattice）上で Viterbi動的計画法 により最尤分割 x* = argmax ∑ log p(xi) を厳密に求める。
⚡ 任意な分割境界の罠［Karpathy 2024 L104］：GPT-2/4では 127 は1トークンだが、677 は " 6" + "77"、8041 は " 8" + "041" に分裂する。LLMはこの恣意的な分割を内部パラメータで吸収せざるを得ない。

ステージ②：Embedding Lookup (WE) と初期残差ストリーム x0 離散IDから連続ベクトル空間 ℝd_model へ
②-A ルックアップ表 x0 = WE[idx] ∈ ℝL × d_model |V| × dmodel 行列
各トークン整数IDは学習可能行列 WE（例：GPT-2で 50,257 × 768、GPT-4で 100,277 × d）の対応する行ベクトルを抜き出す（ワンホット積 WE · eidx）。これがResidual Stream（残差ストリーム）の初期値 x0 となる［Elhage+ 2021 / Karpathy 2024］。
②-B 帯域確保の幾何学 Embedding / Unembedding が占める部分空間 PCA急速減衰［Elhage+ 2021］
大次元 dmodel のモデルで WE と WU（Unembedding）を結合して主成分分析（PCA）を行うと、特異値スペクトルは急速に減衰し、初期トークン埋め込みは全次元のうちごく一部の部分空間しか占有しない。これにより大半の次元が「後続のAttention/MLP層が中間計算を書き込む空きメモリ（通信帯域）」として温存される［Elhage+ 2021 L164］。
②-C 埋め込み空間の異常点 Glitch Tokens（重心付近の未学習トークン群） Dist: 0.0628［GPT-J］
WE の全トークン雲の重心（Centroid）に最も近いトークンを探索すると、' SolidGoldMagikarp'（Index 43453）や ' RandomRedditorWithNo'、'cloneembedreportprint' 等が出現。トークナイザ作成時のWebスクレイピングには頻出したが、モデル本体の厳選訓練データからは除外されたため勾配更新を一度も受けず初期値付近に取り残された［Rumbelow & Watkins 2023］。
⚡ Special Token Injection（特殊トークンの罠）［Karpathy 2024 README L75］：ユーザー入力中に <|endoftext|>（ID 100257）等の特殊トークン文字列が混入するとモデルが突然停止する。allowed_special の明示制御が不可欠。

ステージ③：位置符号化の注入と RoPE（Rotary Position Embedding） 置換同変な Self-Attention に順序と相対距離を与える
③-A 相対位置の要請 内積が相対距離 (m − n) のみに依存する条件［Su+ 2021］ RoFormer 原典
絶対位置加算 xm + pm は残差ストリームを位置情報で汚染し、Attention内積展開時に交差項が複雑化する。RoPEは Query qm と Key kn の内積がトークン内容 xm, xn と相対距離 (m − n) のみの関数 g になることを要請する：
⟨f_q(x_m, m), f_k(x_n, n)⟩ = g(x_m, x_n, m − n) ⇒ f_{q,k}(x_m, m) = R^d_{Θ, m} W_{q,k} x_m
③-B 2次元部分空間の回転 ブロック対角回転行列と波長スペクトル 基底 b = 10000
隠れ次元 d を d/2 個の2次元ペア (2i, 2i+1)（複素数平面 ℂd/2）に分割し、位置 m に応じて角度 mθi だけ回転させる。直交行列の性質 (Rm)T Rn = Rn−m により、内積には差 (n − m)θi だけが残る：
θ_i = 10000^{-2(i-1)/d}, 波長 λ_i = 2π / θ_i = 2π · 10000^{2(i-1)/d} (2π 〜 2π·10000 tok)
高周波（小さい i）は局所的な隣接順序を分解し、低周波（大きい i）は長距離の文脈関係を符号化する。また Abel変換により相対距離 |m − n| の増大に伴い内積上界が自然減衰（Long-term decay）する［Su+ 2021 L340, L572］。
✓ RoPE vs ALiBi の注入点の違い：RoPEは WQ, WK 射影直後に回転行列を乗算する（WV には位置を入れない）。一方 ALiBi［Press+ 2022］は埋め込みを一切変えず、Attentionスコアに距離比例ペナルティ qi kjT − m·|i − j| を直接減算する。

① 数値計算の桁境界ズレ
（L2R vs R2L 分割）		 GPT-3.5/4は1〜3桁の数値を単一トークンとして持つが、デフォルトで左から右（L2R）に3桁ずつ区切るため、繰り上がりで答えの桁数が増えると入力と出力のトークン境界が1桁分ズレる ・Singh & Strouse (2024)［arXiv:2402.14903］：7〜9桁加算でカンマにより右から左（R2L）分割を強制すると精度が最大+20%向上（1-shot: L2R 68.5% vs R2L 95.6%）
・最終繰り上がりがあるLength Mismatch条件ではL2R精度が 8.25% へ崩壊し、誤答の91.25%で「上から4桁目（第2トークン先頭）」を規則的に誤る		 ・1桁分割（Single-digit）：LLaMA / PaLM / Mistralは split_digits=True で0〜9を1文字ずつ分割
・推論時CoTでモデル自身にR2L（カンマ区切り）へ書き直させてから計算させると精度回復
② 多言語の分割長格差
（Tokenization Unfairness）		 英語偏重の語彙やUTF-8バイト効率差により、非ラテン文字圏では1単語が多数の微細トークン（またはバイト列）に細切れになり、実効コンテキスト長と学習効率が激減する ・Petrov+ (NeurIPS 2023)［arXiv:2305.15425］：同一翻訳文のトークン数が英語比でイタリア語1.6倍、ブルガリア語2.6倍、アラビア語3倍、シャン語/ビルマ語で最大15倍（ByT5等バイト型でも4倍超）
・Ali+ (2023)［arXiv:2310.08754］：2.6Bモデル24本の実測で、英語中心トークナイザの多言語流用は追加学習コスト最大+68%と下流性能の深刻な劣化を招いた（欧州5言語でも語彙サイズ3倍が必要）		 ・ターゲット言語のコーパス比率に合わせた語彙構築または語彙拡張
・注意：Parity/Fertility等の内在指標だけでは下流性能を完全には予測できない［Ali+ 2023］
③ Glitch Tokens
（未学習トークンの暴走）		 トークナイザ学習データ（生のWeb/Reddit/GitHub）とLLM事前学習データ（厳選・フィルタ後）の不一致により、語彙IDは存在するが訓練中に一度も活性化しなかったトークンが残る ・Rumbelow & Watkins (2023)：GPT-Jの埋め込み空間で重心からの距離最小上位に ' SolidGoldMagikarp'（距離 0.0628、Reddit r/counting 集計ボット由来のユーザー名）等が集積
・復唱を指示するとTemp=0でも 'distribute' に置換、無言停止、あるいは幻覚・回避応答を誘発		 ・トークナイザ訓練コーパスとモデル事前学習コーパスのフィルタ基準を一致させる
・学習後の WE で重心距離・ノルム異常の未学習トークンを監査・除去
④ 文字列操作不能・
未知語バイト膨張		 1トークンに複数文字がパックされるため文字単位のインデックスが見えない。また語彙外の漢字・絵文字はByte FallbackでUTF-8の3〜4バイトトークンへ分解される ・Karpathy (2024)：単語反転・文字数カウント・綴り問題で失敗。GPT-2ではPythonインデント空白が個別トークンになりコード生成効率が大幅低下（GPT-4で連続空白トークン化により解決）

区分・方式 数理定式化・学習アルゴリズム 推論時の動作・計算特性 長所・短所と主な採用モデル
BPE
（Byte-Pair Encoding）		 辞書（置換）圧縮原理：文字/バイト列から最頻出隣接対 (a, b) を貪欲に反復結合し、総トークン数を最小化 学習されたマージ規則リストを優先度順に決定論的に適用（確率分布は持たない） ・実装が単純で圧縮率が高い
・複数分割候補の確率サンプリングは不可
・採用：GPT-2/3/4 (tiktoken), Llama 3, Mistral
Unigram LM
（ユニグラム言語モデル）		 エントロピー符号化原理：P(x) = ∏ p(xi) を仮定し、大語彙からEM法と尤度損失 lossi でトップダウンに剪定 文字位置を頂点とする分割格子（Lattice）上で Viterbiアルゴリズム により ∑ log p(xi) 最大経路を探索（l-bestサンプリング可） ・Subword Regularizationが可能で多言語・屈折語の下流性能で優位な報告［Ali+ 2023］
・採用：T5, mT5, ALBERT, XLNet, llm-jp
Sinusoidal / Learned APE
（絶対位置加算）		 位置 m のベクトル pm（正弦波 sin/cos(m/100002i/d) または学習パラメータ）を入力埋め込みへ加算：xm + pm 第1層入力時のみ加算。Attention内積 (xm+pm)T WQT WK (xn+pn) に4つの交差項が発生 ・残差ストリームに直接位置情報が混入
・学習長 L を超える外挿能力が極めて弱い［Press+ 2022 Fig.1］
・採用：初代Transformer, BERT, GPT-1/2/3
ALiBi
（線形距離バイアス）		 埋め込みには位置を加算せず、Query-Key内積スコアに距離比例ペナルティを加算：softmax(qi kjT − m·|i − j|) ヘッドごとに幾何級数の傾き m ∈ {2−8/H, …} を固定設定（追加学習パラメータ0） ・L=1024 学習で 2048 外挿時にSinusoidal 2048 学習と同等PPL、訓練11%高速・メモリ11%減
・採用：BLOOM, MPT, Falcon (一部)
RoPE
（回転位置埋め込み）		 各Attention層の qm, kn に2次元回転行列 RdΘ, m を乗算し、内積を相対距離 (m − n) の関数にする 要素積と sin/cos テーブルで O(d) 計算。線形Attentionにも適用可能［Su+ 2021］ ・相対位置と距離減衰を自然に表現し現在のデファクト標準
・学習長超の直接外挿では破綻（→ 上級Rank IIのPI/NTK/YaRNへ）
・採用：LLaMA 1/2/3, PaLM, Qwen, Gemma
① Gage (1994) から NLP BPE へ Sennrich+ 2016
元はデータ圧縮アルゴリズムだったBPEをNMTの希少語・複合語（例：Abwasser|behandlungs|anlage）分割へ導入。固定語彙のまま未知語（UNKs）をゼロにするOpen-Vocabulary翻訳を実現し、語彙サイズと系列長のトレードオフを解決した。
出典: arXiv:1508.07909 L59, L129, L154
② Subword Regularization Kudo 2018
1つの文には複数の妥当な部分語分割が存在する（例：["un","lock"] と ["u","n","lock"]）。学習ステップごとに温度パラメータ α つき分布 P(x|X) ∝ P(x)α から分割をサンプリングすることで擬似データ拡張として機能し頑健性を高める。
出典: arXiv:1804.10959 L73, L206-233
③ SentencePiece 4モジュール Kudo & Richardson
①Normalizer（NFKC等のUnicode正規化）→ ②Trainer（生文からBPE/Unigram語彙学習）→ ③Encoder（文字列→ID列）→ ④Decoder（▁を空白へ戻す逆変換）をC++で一体化し、日本語等の分かち書き前処理を不要にした。
出典: arXiv:1808.06226 L82-104
④ 算術エラーの類型性 Singh & Strouse
GPT-3.5/4のL2R加算エラーはランダムな近似誤差ではなく「最初の3桁（第1トークン）はほぼ100%正解し、4桁目（第2トークン先頭）を必ず間違える」という極めて規則的なパターンを示す。残余エラーの96%（R2L 24/25件、L2R 53/56件）も境界のOff-by-one誤差。
出典: arXiv:2402.14903 L264, L290, L324
⑤ RoPE と V行列の非対称性 Transformer Circuits
RoPEは各層のQuery WQ と Key WK のみに回転行列を作用させ、Value WV には位置情報を直接与えない。そのためRoPEモデルが「1つ前のトークン」の情報を次層へ伝えるには、第1層ヘッドが内容を部分空間へコピーし第2層がK-Compositionで読む必要がある。
出典: Transformer Circuit Exercises Ex.3
⑥ 埋め込み重心の逆転現象 Rumbelow+ 2023
GPT-2 smallやGPT-Jでは未学習のGlitch Tokenは全トークン雲の重心（Centroid）に最も近い場所に集まるが、GPT-2 XLでは逆に重心から最も遠い外縁部に集まる［L462］。いずれも通常トークンとは異なる特異な幾何学的クラスタを形成する。
出典: SolidGoldMagikarp L100-108, L462
概念比較①：手続きとしての BPE vs 確率モデルとしての Unigram LM Kudo (2018) / kojikojiprg
BPE：「最頻出の隣接ペアを順番にマージする」という構築手続き（Procedure）であり、分割に対する生成確率 P(x) を定義しない（シャノン情報理論における辞書置換圧縮に対応）。
Unigram LM：部分語列の明示的な生成確率モデル P(x) = ∏ p(xi) であり、最適符号長 −log p(s) の合計を最小化するエントロピー符号化器として定式化される［Kudo 2018 L194-205］。
概念比較②：SentencePiece / HuggingFace tokenizers / tiktoken の実装差 SentencePiece Docs
SentencePiece（Google）：C++実装、BPEとUnigramの両対応、byte_fallback 対応、UTF-8生バイト入出力とZero-copy NumPy変換・GIL完全解放をサポート。
tiktoken（OpenAI）：Rust実装、推論専用の高速Byte-level BPE（新規語彙の学習機能は非搭載、学習と内部再現にはKarpathyの minbpe 等の RegexTokenizer を用いる）。
概念比較③：正弦波位置埋め込みの回転性と RoPE の回転性の決定的な違い Su+ (2021) / kojikojiprg
正弦波方式（Vaswani+ 2017）：PE(m+k) = M(k)PE(m) という回転構造を持つが、トークン埋め込みに加算されるため、Attention内積では回転行列の直交相殺が起きない。
RoPE（Su+ 2021）：回転行列 R(mθ) を Query・Key ベクトル自体に乗算するため、内積 (R(mθ)q)T(R(nθ)k) = qT R((n−m)θ)k で厳密に相対位置差のみが現れる。
